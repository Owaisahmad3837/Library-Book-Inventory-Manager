# Library Management System

A simple **Library Management System** built with Python to practice real-world programming and DSA concepts.

## Features

* Add new books
* Search books by ID, name, or author
* Issue and return books
* View library reports
* Store and load data using JSON
* Use Python dictionaries for fast book lookup

## Concepts Used

* Python
* Dictionaries / HashMap
* Lists and iteration
* Functions
* Basic OOP
* JSON data persistence
* Time complexity (O(1), O(n))

## Project Purpose

This project was built as an **internship practice project** to improve Python, DSA, data structures, and problem-solving skills.
